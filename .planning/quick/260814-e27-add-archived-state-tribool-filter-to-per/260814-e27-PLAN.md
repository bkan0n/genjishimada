# Quick Task 260814-e27: Archived filter on personal records

## Goal

A community user asked to filter their personal records by whether the map is
archived. Add a tribool `archived` filter — `all` / `archived` / `not_archived` —
to both personal-records endpoints, defaulting to `all` so nothing existing breaks.

## Key finding from scouting

In **both** queries the `rank()` window function is computed *before* the join to
`core.maps`:

- `fetch_user_completions`: `rankable`/`nonrankable` rank over `split` ←
  `latest_per_user_all` (all users, all maps). The `target_map` join happens later,
  in `with_map`.
- `fetch_world_records_per_user`: `ranked` ranks over `latest_per_user_per_map`;
  the `core.maps` join happens later, in `with_map`.

So restricting which maps are returned cannot change a record's rank on the maps
that *are* returned. This is what makes a `core.maps`-level predicate correct — a
post-join filter would have been equally safe here, but the map-level predicate
also keeps `COUNT(*) OVER()` (`total_results`, used for pagination) consistent
with the filtered set.

## Tasks

### Task 1 — SDK type

**files:** `libs/sdk/src/genjishimada_sdk/completions.py`

**action:** Add `ArchivedFilter = Literal["all", "archived", "not_archived"]` next to
the existing `SuspiciousFlag` alias; add `"ArchivedFilter"` to `__all__`
(alphabetical — it sorts first).

**verify:** `just lint-sdk`

**done:** `from genjishimada_sdk.completions import ArchivedFilter` resolves.

### Task 2 — Repository + service + route

**files:** `apps/api/repository/completions_repository.py`,
`apps/api/services/completions_service.py`, `apps/api/routes/v3/completions.py`

**action:**
- `fetch_user_completions`: add keyword param `archived: str = "all"`. Add to the
  `target_map` CTE, bound as `$5`:
  `AND ($5::text = 'all' OR (archived IS TRUE) = ($5::text = 'archived'))`.
  Pass the value in the `fetch(...)` call.
- `fetch_world_records_per_user`: add the same param, bound as `$2`, on the
  `core.maps` join in `with_map`:
  `AND ($2::text = 'all' OR (m.archived IS TRUE) = ($2::text = 'archived'))`.
- Services: thread `archived: ArchivedFilter = "all"` through both methods.
- Routes: add `archived: ArchivedFilter = "all"` query parameter to both handlers,
  with a `Parameter` description. No logic in the handler beyond passthrough.

**verify:** `just lint-api`

**done:** Both endpoints accept the parameter; `archived=all` produces a query whose
results match the pre-change query.

### Task 3 — Bot surface

**files:** `apps/bot/extensions/api_service.py`, `apps/bot/extensions/completions.py`

**action:**
- `api_service.get_completions_for_user` / `get_world_records_for_user`: add
  `archived: ArchivedFilter = "all"` and include it in `params`.
- `/user-completions` and `/world-records` commands: add an optional
  `archived` option using `app_commands.Choice[str]` with readable labels
  ("All", "Archived only", "Not archived"), defaulting to `all` when omitted, and
  pass it through the `partial(...)` fetch func.

**verify:** `just lint-bot`

**done:** Both slash commands expose the three choices; omitting the option
behaves exactly as today.

### Task 4 — Tests

**files:** `apps/api/tests/repository/completions/test_completions_repository_archived_filter.py`

**action:** Seed one archived and one non-archived map with a verified completion for
one user. Assert, for both repository methods:
- default / `"all"` → both maps present (non-breaking default)
- `"archived"` → only the archived map
- `"not_archived"` → only the non-archived map

**verify:** `just test-api`

**done:** New tests pass; existing completions tests still pass.

## Non-goals

- Changing the default to `not_archived`.
- Applying the filter to map leaderboards, moderation records, or the dashboard.
