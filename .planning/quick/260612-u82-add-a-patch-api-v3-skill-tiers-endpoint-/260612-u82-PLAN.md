<objective>
Add `PATCH /api/v3/skill/tiers` — an admin endpoint to tune the skill tier `percentiles`
array (the only tunable in the percentile tier system from quick task 260612-pyo). Symmetric
with the existing `PATCH /api/v3/skill/config` (weights): gated by the `skill:admin` sentinel
scope, validates the percentiles array (exactly 6, strictly increasing, all in `(0,1)`),
persists to `skill.tier_config.percentiles`, re-derives `boundaries` via the existing
`compute_tier_boundaries` on the SAME connection, and returns the updated `SkillTiersResponse`.

Purpose: let an admin retune the tier cut-points without a code change or a full score
recompute. Scores are unchanged — only the percentile config and the derived boundaries move.
Output: SDK request struct, repo `update_percentiles`, a domain validation exception, service
`update_tier_config`, the PATCH route, and tests for happy path / validation-rejection / auth gate.
</objective>
