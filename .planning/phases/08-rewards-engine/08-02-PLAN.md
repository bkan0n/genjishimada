<objective>
Build the rewards business logic: extract a transaction-aware XP grant helper from
LootboxService, then implement TournamentRewardService with the participation,
placement, and streak-bonus grant paths. All XP delivery reuses the existing
lootbox.xp upsert + generic XpGrantEvent publish contract that the bot consumer
(apps/bot/extensions/xp.py:106) already owns — the tournament-specific
TournamentXpGrantEvent has zero consumers and MUST NOT be published.

Purpose: This is the core of the phase. Every grant is guarded by the 08-01 ledger
(claim_xp_grant) for at-least-once safety and runs inside the caller's transaction so
the ledger insert + lootbox.xp upsert are atomic. The hooks that invoke this service
are wired in 08-03. NOTE: this plan delivers the participant-side streak increment +
bonus only; the non-participant streak RESET sweep needs the full tracked-user set
(broader than one event's category scope) and is owned by 08-03's outbox hook.

Output: a conn-accepting helper, the new reward service with full unit-test coverage
(mocked publish seam), and any reward-specific domain exceptions.
</objective>

  fetch_xp_multiplier(self, *, conn=None) -> float | int        (line 262)
  upsert_user_xp(self, user_id, xp_amount, multiplier, *, conn=None) -> dict  (line 539)
    returns {"previous_amount": int, "new_amount": int}

Canonical grant pattern to extract (lootbox_service.py:373-417 grant_user_xp):
  multiplier = fetch_xp_multiplier() -> upsert_user_xp(...) -> build XpGrantEvent(prev,new)
  -> publish_message(routing_key="api.xp.grant", data=event, headers=headers)

08-01 repo methods (tournaments_repository.py):
  claim_xp_grant(cycle_id, user_id, reason, amount, *, conn=None) -> bool  (True on first claim)
  advance_streak(user_id, cycle_id, participated: bool, *, conn=None) -> dict
  fetch_cycle_participants(cycle_id, *, conn=None) -> list[int]
  fetch_all_streak_user_ids(*, conn=None) -> list[int]  (all tracked users; used by 08-03 reset sweep, not here)
  fetch_category(category_id, *, conn=None) -> dict | None  (read participation_xp/placement_xp/streak_xp jsonb)

SDK structs (genjishimada_sdk.tournaments):
  TournamentCycleCompletedEvent(cycle_id, category_id, standings, winner_user_id)
  TournamentLeaderboardEntryResponse(rank, user_id, name, time, verified, completion)
  PlacementXpTier(place, xp); StreakXpTier(threshold, xp)

publish_message (services/base.py): kw_only; api.xp.grant ∈ IGNORE_IDEMPOTENCY so
