| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-06-02 | Tampering | cycle_id path parameter | mitigate | Litestar path param typing ("{cycle_id:int}") rejects non-integer; service validates cycle existence |
| T-06-03 | Tampering | Unauthorized submission scope bypass | mitigate | opt={"required_scopes": {"tournaments:write"}} on submit endpoint; scope_guard rejects missing scope with NotAuthorizedException |
| T-06-04 | Information Disclosure | Leaderboard enumeration | accept | Leaderboard data is intentionally public community data; tournaments:read scope still required |
| T-06-05 | Elevation of Privilege | Read-only user accessing write endpoint | mitigate | tournaments:write scope separate from tournaments:read; scope guard enforced per endpoint |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase |
