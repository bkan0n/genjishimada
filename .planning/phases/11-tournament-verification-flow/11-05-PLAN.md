## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Discord user → bot button | a moderator clicks Accept/Reject; the verdict crosses into a state-changing API call |
| bot → verify API | the bot must authenticate (X-API-KEY) and the verdict only takes effect via the tournaments:verify endpoint — the bot never writes the DB |
| RabbitMQ → bot consumer | event payload (screenshot/video URLs, mentions) renders into a Discord embed |
