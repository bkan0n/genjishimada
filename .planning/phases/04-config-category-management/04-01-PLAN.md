Module docstring: `"""Service for tournament domain business logic."""`

Imports needed: `from __future__ import annotations`, `msgspec` (for UNSET checks, convert, json.encode), `Pool` from asyncpg, `State` from litestar.datastructures, SDK types (`TournamentCategoryCreateRequest`, `TournamentCategoryPatchRequest`, `TournamentCategoryResponse`, `TournamentConfigPatchRequest`, `TournamentConfigResponse`), `UniqueConstraintViolationError` from repository.exceptions, `TournamentRepository` from repository.tournaments_repository, `BaseService` from services.base, domain exceptions (`CategoryLockedError`, `CategoryNameExistsError`, `CategoryNotFoundError`) from services.exceptions.tournaments.

Constructor receives `pool: Pool`, `state: State`, `tournament_repo: TournamentRepository`. Store repo as `self._tournament_repo`.

Methods to implement (7 total):

1. `async def get_config(self) -> TournamentConfigResponse` — Calls `self._tournament_repo.fetch_config()`, converts result with `msgspec.convert(config, TournamentConfigResponse)`. Per D-09, no empty check needed.

2. `async def update_config(self, data: TournamentConfigPatchRequest) -> TournamentConfigResponse` — Per D-08, iterate TournamentConfigPatchRequest fields: check `data.blacklist_weeks is not msgspec.UNSET`, build updates dict. If updates non-empty, call `self._tournament_repo.update_config(updates)`. Then fetch and return config via `get_config()`.

3. `async def create_category(self, data: TournamentCategoryCreateRequest) -> TournamentCategoryResponse` — Per D-06, NO active cycle check. Pre-serialize JSONB fields: `msgspec.json.encode(data.placement_xp).decode()` for placement_xp, same for streak_xp. Convert difficulties list items to strings: `[str(d) for d in data.difficulties]`. Call `self._tournament_repo.create_category(name=data.name, difficulties=..., cycle_frequency=data.cycle_frequency, participation_xp=data.participation_xp, placement_xp=<serialized>, streak_xp=<serialized>, champion_role_id=data.champion_role_id)`. Wrap in try/except for `UniqueConstraintViolationError` — if `"name"` in `e.constraint_name or ""`, raise `CategoryNameExistsError(data.name)` from e, else re-raise. Convert result with `msgspec.convert(row, TournamentCategoryResponse)`.

4. `async def list_categories(self) -> list[TournamentCategoryResponse]` — Calls `self._tournament_repo.fetch_categories()`, converts each row with `msgspec.convert`. Returns `[msgspec.convert(row, TournamentCategoryResponse) for row in rows]`.

5. `async def get_category(self, category_id: int) -> TournamentCategoryResponse` — Calls `self._tournament_repo.fetch_category(category_id)`. If result is None, raises `CategoryNotFoundError(category_id)`. Returns `msgspec.convert(row, TournamentCategoryResponse)`.

6. `async def update_category(self, category_id: int, data: TournamentCategoryPatchRequest) -> TournamentCategoryResponse` — Per D-05, acquires pool connection with `async with self._pool.acquire() as conn:`. Builds updates dict by checking each field of TournamentCategoryPatchRequest against `is not msgspec.UNSET`. Fields requiring special handling: `difficulties` needs `[str(d) for d in data.difficulties]`, `placement_xp` needs `msgspec.json.encode(data.placement_xp).decode()`, `streak_xp` needs same. Other fields (name, cycle_frequency, participation_xp, champion_role_id, is_active) pass through directly. Then calls `self._tournament_repo.check_active_cycle_for_category(category_id, conn=conn)`. If result is not None (returns cycle_id), raises `CategoryLockedError(category_id, cycle_id=result)`. Then calls `self._tournament_repo.update_category(category_id, updates, conn=conn)` wrapped in try/except for `UniqueConstraintViolationError` (same name constraint check as create_category, using `updates.get("name", "")` for the error). If update returns None, raises `CategoryNotFoundError(category_id)`. Returns `msgspec.convert(row, TournamentCategoryResponse)`.

7. `async def delete_category(self, category_id: int) -> None` — Per D-05 and D-07, acquires pool connection. Calls `check_active_cycle_for_category(category_id, conn=conn)` — if not None, raises `CategoryLockedError(category_id, cycle_id=result)`. Calls `self._tournament_repo.delete_category(category_id, conn=conn)` — if False, raises `CategoryNotFoundError(category_id)`.

Provider function at bottom: `async def provide_tournament_service(state: State, tournament_repo: TournamentRepository) -> TournamentService:` returns `TournamentService(state.db_pool, state, tournament_repo)`.

Use `# type: ignore[arg-type]` on conn= arguments where the MagicMock context manager connection type doesn't match `Connection` (following existing maps_service.py pattern).
