## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest 8.x (pytest-asyncio auto, pytest-databases[postgres]) |
| **Config file** | `apps/api/pyproject.toml` (note: `addopts = --testmon`) |
| **Quick run command** | `uv run --directory apps/api pytest tests/repository/tournaments/test_outbox_poller.py -v -p no:xdist` |
| **Full suite command** | `uv run --directory apps/api pytest -n 4 --no-testmon` |
| **Estimated runtime** | ~90–180 seconds (full, parallel) |

> **Testmon trap:** a green `just test-api` can hide failures because testmon
> silently deselects unaffected tests. Multi-file targeted runs MUST pass
> `--no-testmon`. The only true full-suite check is `pytest -n 4 --no-testmon`.
> Set `X-PYTEST-ENABLED=1` to skip queue publishing in tests.

- **After every task commit:** Run the relevant targeted file with `-p no:xdist`
- **After every plan wave:** Run `uv run --directory apps/api pytest -n 4 --no-testmon`
- **Before `/gsd:verify-work`:** Full suite must be green (`--no-testmon`)
- **Max feedback latency:** 180 seconds
