<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| outbox poller → RabbitMQ | API-internal background task publishes events; no per-request auth; bot consumes downstream |
| pending_transitions.payload → msgspec.convert → published event | DB-generated payload deserialized into SDK struct before it leaves the API |
| multiple API instances → same outbox rows | concurrent pollers must not double-publish |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Repudiation/Integrity | double-publish across API instances | mitigate | `FOR UPDATE SKIP LOCKED` + mark-published in the same transaction; cycle-scoped idempotency key `tournament:{event_type}:{cycle_id}`; downstream Phase 9 dedupes via public.idempotency_claims |
| T-07-06 | Tampering/Validation | poisoned pending_transitions.payload | mitigate | `msgspec.convert(payload, Struct)` validates payload→struct before publish (V5 partial); a malformed payload raises and the row stays unpublished (not silently shipped) |
| T-07-07 | Denial of Service | poison row re-failing every tick / unbounded outbox growth | accept | Per-tick broad `except` + `log.exception` (Sentry-captured) keeps the loop alive; retry cap / DLQ for stuck rows deferred to a follow-up (RESEARCH Open Question 3) |
| T-07-08 | Denial of Service | orphaned background task on shutdown | mitigate | Lifespan `finally` cancels the task and awaits it with `suppress(CancelledError)`; `CancelledError` is re-raised inside the loop so cancellation propagates |
| T-07-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this phase (zero external packages per RESEARCH audit); no checkpoint needed |
</threat_model>
