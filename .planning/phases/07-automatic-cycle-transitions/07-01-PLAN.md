<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pg_cron → process_cycle_transitions() | Automated DB-internal invocation with elevated access, no per-request auth |
| cycles/categories rows → transition logic | DB-stored data drives interval math and selection; a malformed row could misroute a transition |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | dynamic interval/selection SQL in process_cycle_transitions | mitigate | All SQL static; frequency mapped via `CASE` (CHECK-constrained enum), never string-concatenated; `make_interval(days => int)` used; difficulties passed as array, not interpolated |
| T-07-02 | Elevation/Integrity | advisory lock correctness (double-transition risk) | mitigate | `pg_try_advisory_xact_lock(2025070100)` non-blocking, unique constant documented as non-colliding; auto-release on commit eliminates leaked-lock DoS; whole run is one transaction so concurrent ticks no-op |
| T-07-03 | Tampering | select_eligible_map returning an ineligible/archived map | mitigate | Helper filters `official=TRUE AND archived=FALSE AND code IS NOT NULL`; LRU fallback uses same filter; NULL result skips pre-roll rather than inserting a bad map |
| T-07-04 | Denial of Service | transition aborting the whole run on one bad category | accept | D-07: missing pending cycle / no eligible map downgrade to `RAISE NOTICE` + skip that category; the loop continues; next cron tick retries |
| T-07-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this phase (RESEARCH Package Legitimacy Audit: zero external packages); no checkpoint needed |
</threat_model>
