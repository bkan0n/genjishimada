1. create_tournament_completion(cycle_id, user_id, map_id, time, screenshot, video=None, *, conn) -> dict:
   INSERT INTO tournaments.completions (cycle_id, user_id, map_id, time, screenshot, video) VALUES ($1, $2, $3, $4, $5, $6) RETURNING *.
   Wrap in try/except catching UniqueViolationError (cycle_id, user_id, inserted_at UNIQUE), ForeignKeyViolationError (cycle_id, user_id, map_id FKs).

2. cross_write_to_core(tournament_completion_id, user_id, map_id, time, screenshot, video=None, *, conn) -> int | None:
   Per D-03, D-04, D-05 -- the most critical query in the repository.
   CTE structure:
   - current_best: SELECT MIN(c.time) AS best_time FROM core.completions c WHERE c.user_id = $2 AND c.map_id = $3 AND c.legacy = FALSE
   - should_insert: CASE WHEN cb.best_time IS NULL THEN TRUE WHEN $4 < cb.best_time THEN TRUE ELSE FALSE END AS do_insert FROM current_best cb
   - map_flags: SELECT m.official, (m.playtesting = 'In Progress') AS in_playtest FROM core.maps m WHERE m.id = $3
   - computed: SELECT (mf.in_playtest OR $6::text IS NULL OR $6::text = '' OR NOT mf.official) AS completion_flag FROM map_flags mf
   - INSERT INTO core.completions (map_id, user_id, time, screenshot, video, completion, tournament_completion_id) SELECT $3, $2, $4, $5, $6, co.completion_flag, $1 FROM should_insert si CROSS JOIN computed co WHERE si.do_insert = TRUE RETURNING id
   Parameters: tournament_completion_id=$1, user_id=$2, map_id=$3, time=$4, screenshot=$5, video=$6.
   Returns the new core.completions id via fetchval, or None if skipped (time not faster).
   The CTE avoids the enforce_speed_rules_nonlegacy_only() trigger by pre-checking -- if tournament time >= best, no INSERT happens at all (D-05 no-op behavior).

3. fetch_leaderboard(cycle_id, *, conn) -> list[dict]:
   Per D-06, D-07 -- two-stage query using CTE.
   CTE best_per_user: SELECT DISTINCT ON (tc.user_id) tc.user_id, tc.time, tc.verified, tc.completion FROM tournaments.completions tc WHERE tc.cycle_id = $1 ORDER BY tc.user_id, tc.verified DESC, tc.time ASC
   Outer query: SELECT RANK() OVER (ORDER BY bpu.verified DESC, bpu.time ASC)::int AS rank, bpu.user_id, COALESCE(u.global_name, u.nickname, 'Unknown') AS name, bpu.time::float AS time, bpu.verified, bpu.completion FROM best_per_user bpu JOIN core.users u ON u.id = bpu.user_id ORDER BY bpu.verified DESC, bpu.time ASC
   Return [dict(row) for row in rows].

4. fetch_user_completion(cycle_id, user_id, *, conn) -> dict | None:
   SELECT * FROM tournaments.completions WHERE cycle_id = $1 AND user_id = $2 ORDER BY verified DESC, time ASC LIMIT 1.
   Returns user's best tournament completion for the cycle, or None.

| Boundary | Description |
|----------|-------------|
| Repository -> PostgreSQL | SQL queries executed against database; all inputs parameterized |
| Repository -> asyncpg | Exception handling translates asyncpg errors to repository exceptions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | SQL queries | mitigate | All values use positional $N parameters (never f-string interpolation in query values). Dynamic SET clause only interpolates column NAMES from allowlist, not values. |
| T-03-02 | Tampering | cross_write_to_core CTE | mitigate | CTE pre-checks best time before INSERT to avoid speed trigger bypass. Trigger still fires as safety net on any actual INSERT. |
| T-03-03 | Elevation of Privilege | update_category dynamic UPDATE | mitigate | Field names come from a dict whose keys should be validated by service layer. Repository uses f-string for column names but values are always positional parameters. Service layer (Phase 4) must validate field allowlist. |
| T-03-04 | Information Disclosure | fetch_leaderboard | accept | Leaderboard data (user_id, name, time, rank) is intentionally public tournament data. No PII beyond display name. |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase -- all dependencies already exist in pyproject.toml |
