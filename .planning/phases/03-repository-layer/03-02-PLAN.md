Test class structure:

class TestFetchConfig:
  - test_fetch_config_returns_singleton: call fetch_config, assert result has blacklist_weeks key with int value, has created_at and updated_at keys.

class TestUpdateConfig:
  - test_update_config_changes_blacklist_weeks: update blacklist_weeks to 8, fetch_config again, assert blacklist_weeks == 8. Reset back afterward if needed (tests share DB state).

class TestCreateCategory:
  - test_create_category_returns_dict: create with name, difficulties=["Hard"], assert result has id, name, difficulties, cycle_frequency keys.
  - test_create_category_duplicate_name_raises: create two with same name, assert raises UniqueConstraintViolationError.

class TestFetchCategory:
  - test_fetch_category_by_id: create via fixture, fetch by id, assert name matches.
  - test_fetch_category_not_found: fetch with id=999999, assert result is None.

class TestFetchCategories:
  - test_fetch_categories_returns_list: create 2 via fixture, fetch all, assert len >= 2 (other tests may have created categories).

class TestUpdateCategory:
  - test_update_category_name: create via fixture, update name, assert returned dict has new name.
  - test_update_category_jsonb_fields: create via fixture, update placement_xp with '[{"place": 1, "xp": 500}]' (JSON string for ::jsonb), assert returned dict has updated placement_xp.

class TestDeleteCategory:
  - test_delete_category_returns_true: create via fixture, delete, assert True. Fetch again, assert None.
  - test_delete_nonexistent_returns_false: delete with id=999999, assert False.

class TestCheckActiveCycleForCategory:
  - test_no_active_cycle_returns_false: create category + cycle with status "pending", assert check returns False.
  - test_active_cycle_returns_true: create category + cycle with status "active" (use asyncpg_conn to UPDATE status directly or use create_test_cycle with status="active" override), assert check returns True.

class TestCreateCycle:
  - test_create_cycle_returns_dict: create category, create map via create_test_map, create cycle, assert result has category_id, map_id, status == "pending".

class TestFetchCycle:
  - test_fetch_cycle_by_id: create and fetch, assert match.
  - test_fetch_cycle_not_found: fetch id=999999, assert None.

class TestFetchActiveCycle:
  - test_fetch_active_cycle_returns_active: create cycle, set status to "active" via update_cycle_status, fetch active, assert found.
  - test_fetch_active_cycle_none_when_pending: create cycle (default pending), fetch active, assert None.

class TestUpdateCycleStatus:
  - test_update_to_active: create cycle, update status to "active" with started_at=datetime, assert returned status == "active" and started_at is not None.

class TestFetchCycleHistory:
  - test_fetch_cycle_history_paginated: create category, create 3 cycles, fetch with limit=2 offset=0, assert total >= 3 and len(rows) == 2.

class TestCreateTournamentCompletion:
  - test_create_returns_dict: create category + cycle + user + map, create completion, assert result has cycle_id, user_id, time keys.
  - test_duplicate_raises_unique_violation: create same completion twice (same cycle_id, user_id, inserted_at will conflict if called fast enough -- use explicit inserted_at override in fixture or accept that the UNIQUE constraint includes inserted_at so this may need a direct INSERT with same timestamp).

class TestCrossWriteToCore:
  - test_cross_write_inserts_when_faster: create user + map, call cross_write_to_core with time 25.0, assert returns int (new core.completions id). Verify core.completions row has tournament_completion_id set.
  - test_cross_write_skips_when_slower: create user + map, insert a core.completions row via create_test_completion fixture with time=20.0, then call cross_write_to_core with time=25.0, assert returns None.
  - test_cross_write_skips_when_equal: same setup but cross_write with time == existing best, assert returns None.

class TestFetchLeaderboard:
  - test_leaderboard_ranking_by_time: create cycle with 2 users, user A time=30.0 verified=False, user B time=25.0 verified=False. Fetch leaderboard. Assert user B is rank 1 (faster).
  - test_leaderboard_verified_beats_unverified: create cycle with 2 users, user A time=20.0 verified=False, user B time=30.0 verified=True. Fetch leaderboard. Assert user B is rank 1 (verified beats unverified even with slower time).
  - test_leaderboard_includes_display_name: fetch leaderboard, assert each entry has "name" key.

class TestFetchUserCompletion:
  - test_fetch_user_completion_found: create completion, fetch by cycle_id and user_id, assert result is not None.
  - test_fetch_user_completion_not_found: fetch with unknown user, assert None.

class TestFetchStreak:
  - test_fetch_streak_not_found: fetch streak for unknown user, assert None.

class TestUpsertStreak:
  - test_upsert_creates_new_streak: upsert for user who has no streak, assert current_streak == 1, max_streak == 1.
  - test_upsert_increments_existing: upsert twice for same user (different cycle_ids), assert current_streak == 2.

class TestFetchEligibleMaps:
  - test_eligible_maps_excludes_blacklisted: create 2 maps with difficulty "Medium", create a cycle for one of them, call fetch_eligible_maps(["Medium"], blacklist_weeks=52), assert only the non-cycled map appears.
  - test_eligible_maps_filters_by_difficulty: create map with difficulty "Hard", call fetch_eligible_maps(["Medium"], ...), assert the Hard map is not in results.

class TestFetchLeastRecentlyUsedMap:
  - test_returns_map_never_used: create 2 maps, cycle for one, call fetch_least_recently_used_map(["Medium"]), assert returns the un-cycled map.

class TestCreatePendingTransition:
  - test_create_returns_dict: create cycle, create transition with event_type="cycle_started" and payload="{}", assert result has cycle_id, event_type, published == False.

class TestFetchUnpublishedTransitions:
  - test_returns_unpublished_only: create 2 transitions, mark one published, fetch unpublished, assert only 1 returned.

class TestMarkTransitionPublished:
  - test_marks_published: create transition, mark published, assert returns True. Fetch unpublished, assert transition not in list.
  - test_already_published_returns_false: create and mark, mark again, assert returns False.
